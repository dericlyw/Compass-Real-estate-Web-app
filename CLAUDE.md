# Project notes for Claude

## Social content rules (always apply)
Before drafting, scheduling or approving **any** social post, ad or caption for Compass.RealEstate / TKB, check it against `docs/META_CONTENT_RULES.md`:
- Never write "guaranteed", guaranteed returns or income, "risk-free", "#1", "best value" or invented scarcity.
- Every housing post must carry APDL / advertising permit details (number, validity and authority before any paid boost) and "Artist's impression" on renders.
- No sales CTA attached to deaths, crises, royal or religious occasions, or charity events.
- Agent, staff and KOL posts promoting TKB projects need Meta's Paid Partnership label.
- Don't post the same copy more than once. Each post gets a new angle.

## Tools
- **Buffer** is the only social scheduler. Save drafts first (`saveToDraft`), never `shareNow` without explicit approval.
- **Metricool** is for analytics only (brand id 7973667). Never schedule there.
